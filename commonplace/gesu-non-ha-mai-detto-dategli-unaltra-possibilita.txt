Gesù non ha mai detto "dategli un'altra possibilità"
↳ [torna all'indice](index.html)
↳ [torna all'archivio](archive.html)
↳ [en](https://ivana-rep.github.io/soul/post.html?p=commonplace/jesus-never-said-give-them-another-chance.txt) // it

\ abbiamo confuso la grazia con il dare più possibilità.
\
\ ti feriscono.
\ li perdoni.
\ lo rifanno.
\
\ così dai loro un'altra possibilità.
\ e un'altra ancora.
\ e un'altra ancora.
\
\ perché i cristiani devono mostrare "grazia."
\ ma la grazia è un dono, non un diritto.
\
\ la grazia non è ingenuità.
\
\ la grazia è un favore immeritato.
\ può significare dare a qualcuno un'altra opportunità.
\ ma la Scrittura non definisce mai la grazia come il dare automaticamente una seconda possibilità.
\
\ gli schemi contano.
\ il pentimento conta.
\ i frutti contano.
\ la grazia può essere generosa senza essere ingenua.
\
\ la grazia non garantisce una seconda possibilità.
\
\ Adamo ed Eva ricevettero la misericordia e la grazia di Dio.
\ ma furono comunque allontanati dal giardino — non poterono tornare indietro.
\
\ Mosè fu perdonato.
\ ma non poté comunque entrare nella Terra Promessa.
\
\ la grazia può perdonare l'errore senza dare un'altra possibilità.
\
\ come cristiani, siamo chiamati a essere persone piene di grazia.
\ ma la grazia non significa dare a tutti una seconda possibilità.
\
\ puoi mostrare grazia e comunque...
\ porre fine a una relazione dopo un tradimento.
\ andartene dopo un singolo atto di abuso.
\ prendere le distanze dopo un danno grave.
\
\ la grazia può essere generosa senza dare a qualcuno un'altra opportunità di ferirti gravemente.
\
\ la grazia chiama al cambiamento, non al caos continuo.
\
\ "continuiamo forse a peccare perché la grazia abbondi? no di certo!"
\ — [Romani 6:1-2](post.html?p=bible/romans_6-1-2.txt)
\
\ la grazia biblica non dice: "continua a ferirmi. continuerò a permetterlo."
\ la grazia non è il permesso di persistere in uno schema.
\
\ il vero pentimento produce cambiamento.
\
\ Gesù disse: "fate dunque un frutto degno della conversione."
\ — [Matteo 3:8](post.html?p=bible/matthew_3-8.txt)
\
\ una scusa può accadere in un momento.
\ il pentimento produce frutti nel tempo.
\
\ non ascoltare solo un "mi dispiace."
\ cerca un cambiamento nello schema.
\
\ anche Paolo, a volte, incoraggiava possibilità limitate.
\
\ "dopo un primo e un secondo ammonimento, sta' lontano da chi è fazioso."
\ — [Tito 3:10](post.html?p=bible/titus_3-10.txt)
\
\ Paolo non chiamava grazia le possibilità infinite.
\ a volte la grazia dà una seconda possibilità.
\ a volte la grazia dà più possibilità.
\ ma a volte, con saggezza, la grazia semplicemente se ne va.
\
\ la grazia non può essere pretesa.
\
\ puoi...
\
\ perdonare senza dimenticare il danno.
\ amare senza lasciarti vulnerabile.
\ mostrare misericordia senza mantenere la vicinanza.
\ !!dare grazia senza dare un'altra possibilità.!!
